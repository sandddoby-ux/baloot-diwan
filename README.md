# ديوان البلوت (Baloot Diwan) ⚜️

> المنصة الخليجية الأولى للعب البلوت أونلاين بروح المجلس الأصيل وقوانين الصن والحكم الرسمية المعتمدة.

---

## 📋 نظرة عامة على المشروع (Project Overview)

تم بناء **ديوان البلوت** كمنصة ألعاب متكاملة موجهة للسوق السعودي والخليجي، تركز على:
1. **النزاهة التامة (100% Fair Play):** خالية من أنماط الدفع للفوز (No Pay-to-Win)، وتوزيع عشوائي مشفر بالكامل (32 ورقة عبر خوارزمية Fisher-Yates).
2. **محرك قوانين معتمد:** يطبق قواعد بطولات البلوت الرسمية في الصن، الحكم، الدق، التعلاية، المشاريع (سرة، خمسين، مية، 400، بلوت)، الكبوت، وحساب الخسارة وقيد الـ 152.
3. **أنماط لعب متعددة:**
   - مباراة سريعة أونلاين (Quick Match).
   - ديوانية خاصة برمز سري ورابط دعوة مباشر للأصدقاء.
   - تدريب حر ضد 3 روبوتات ذكية مع 3 مستويات صعوبة (مبتدئ، متوسط، محترف).
   - نمط التعليم التفاعلي خطوة بخطوة.
4. **استراتيجية تحسين محركات البحث (SEO):** صفحات عربية متكاملة وقابلة للزحف والفهرسة (`/rules`، `/learn`، `/scoring`، `/projects_guide`، `/strategies`، إلخ) مع بيانات Schema.org JSON-LD وOpenGraph.
5. **نموذج اشتراكات علمي شفاف (Behavioral Science):**
   - اللعب الأساسي مجاني بالكامل.
   - باقة ديوان بلس الشهرية: 25 ريال سعودي.
   - باقة ديوان بلس السنوية: 199 ريال سعودي (توفير 33%).

---

## 🛠️ البنية التقنية (Architecture & Tech Stack)

- **Frontend:** React 19 + TypeScript + Vite.
- **Styling & Design System:** Tailwind CSS v4، خطوط عربية سعودية وخليجية أنيقة (Tajawal و Amiri).
- **Audio Synthesizer:** Web Audio API مدمج لإنتاج أصوات خبطات الورق وتوزيع الكروت بدون أي ملفات خارجية.
- **State Management & Engine:** محرك ألعاب حتمي (Deterministic Engine) في مجلد `src/engine/`.
- **Payment Abstraction:** يدعم بوابتي `Tap Payments` و `Paymob` للأفراد المستقلين في مصر لبيع الخدمات في الخليج والسعودية مع دعم مدى وApple Pay.

## 💳 بوابات الدفع للأفراد (Payment Gateway Eligibility)

بناءً على البحث والتحقق القانوني:
1. **Tap Payments (الخيار الموصى به):**
   - يدعم فتح حساب فردي/عمل حر (Individual Freelancer) للمصريين باستخدام الرقم القومي والآيبان الشخصي.
   - يدعم الدفع ببطاقات **مدى (Mada)**، و **Apple Pay**، و **Visa/Mastercard** بالريال السعودي (SAR).
2. **Paymob Egypt (الخيار البديل):**
   - إمكانية تفعيل بوابة الدفع الدولية وقبول مدفوعات الخليج والسعودية.
